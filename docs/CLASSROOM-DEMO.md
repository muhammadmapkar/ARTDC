# Classroom demo — 3–5 minutes

For the Vercel phone browser preview and a phone QA checklist, use [PHONE-QA-AND-PRESENTATION.md](PHONE-QA-AND-PRESENTATION.md). The browser preview does not require Expo Go.

## Before class

1. Install dependencies and load RepairLens in Expo Go on an iPhone or Android phone. The demo uses local sample data after installation.
2. Open **Profile → Reset Demo → Reset demo** after any rehearsal. The welcome screen returns.
3. Keep the phone in portrait mode and print `repair-audit-card.html` at A5 size.

## Exact walkthrough

| Time | Tap | Expected transition and speaking point |
| --- | --- | --- |
| 0:00 | **Explore demo as guest** | Welcome → Home. No account is required. |
| 0:20 | **Change or edit vehicle**, select **Toyota Corolla**, **Continue to report a problem** | Vehicle → Report. The sample car is a 2022 Corolla with 85,000 km. |
| 0:40 | **Use sample AC issue**, **See preliminary guidance** | Report → Guidance. Read possible causes and the qualified-mechanic notice; no car was inspected. |
| 1:05 | **Analyze a sample quotation** | Guidance → Quote. AED 750 part + AED 250 labour + AED 100 inspection = AED 1,100. |
| 1:25 | **View Repair Protection Score**, **Generate questions for mechanic** | Quote → Protection. The 65/100 score measures documentation completeness. Read the example question about the part and warranty. |
| 1:55 | **Compare fictional garages**, try **Longest warranty**, then **Lowest price** | Protection → Garages. Part category, warranty and timing matter alongside price. |
| 2:20 | **View Trust Passport** for **Harbour Auto Studio** | Garages → Trust. All profiles, reviews and verification indicators are simulated. |
| 2:40 | **Select Harbour Auto Studio**, **Approve repair · AED 950** | Trust → Quote Lock. The initial estimate was AED 850; the confirmed base quotation is AED 950. |
| 3:00 | **Show additional request**, then **Decline additional work** | Quote Lock records the AED 300 request and preserves the AED 950 authorization. In an alternate run, approval raises it to AED 1,250. |
| 3:25 | **Track this repair**, tap each **Demo next stage** button | Tracking advances through the six simulated stages. Open the sample inspection note. |
| 4:05 | **Collect & save repair history**, **View repair & invoice** | My Garage → Record. The invoice matches the approved scope and total. |
| 4:35 | Show the printed Repair Audit Card | The six checks can guide a customer even away from the app. |

For a shorter presentation, skip sorting and advance the timeline quickly. Media and document selection depend on native modules in the installed Expo client; real files are never analyzed. If selection is unavailable, use the sample issue and quotation.
